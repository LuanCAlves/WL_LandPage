# 💻 WL Serviços de Informática - Landing Page

Uma Landing Page moderna, responsiva e de alta conversão desenvolvida para a **WL Serviços de Informática**, focada em suporte técnico de TI e sistemas de segurança CFTV.

## 🚀 Tecnologias Utilizadas

* **HTML5 & Tailwind CSS**: Estrutura semântica com estilização via utilitários para máxima performance.
* **JavaScript (Vanilla)**: Lógica customizada para manipulação do DOM e efeitos de interface.
* **Font Awesome**: Biblioteca de ícones para auxílio visual e UX.
* **Google Fonts (Outfit)**: Tipografia moderna escolhida para legibilidade e estética tech.
* **FormSubmit API**: Integração para recebimento de leads via e-mail com processamento AJAX (sem recarregamento de página).

## ✨ Diferenciais do Projeto

* **Design Glassmorphism**: Interface baseada em transparências, desfoque (backdrop-filter) e bordas finas, criando um visual futurista.
* **Navegação Dinâmica**: Navbar inteligente que altera o estilo (vidro) automaticamente ao rolar a página para melhorar o foco no conteúdo.
* **Formulário Inteligente**: Script customizado que captura o envio, desabilita o botão para evitar cliques duplos e exibe feedback visual de sucesso.
* **Totalmente Responsiva**: Layout adaptável para smartphones, tablets e desktops.
* **SEO Friendly**: Uso de meta tags de descrição e títulos hierárquicos para melhor ranqueamento.

## 🛠️ Como Visualizar

1.  Clone este repositório:
    ```bash
    git clone [https://github.com/LuanCAlves/WL_LandPage.git](https://github.com/LuanCAlves/WL_LandPage.git)
    ```
2.  Abra o arquivo `index.html` em seu navegador de preferência.

## 📁 Estrutura de Arquivos

* `index.html`: Código fonte principal com configurações do Tailwind.
* `style.css`: Estilos específicos e animações customizadas.
* `fav.ico`: Logotipo utilizado como ícone de aba.
